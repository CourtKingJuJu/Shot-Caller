# Shot-Caller

Play call an mock NFL game vs an ML Shot caller. Can an ML agent without taking in individual players learn the outcome of down-distance, offensive position, defensive position, field position and more.

## Learning Concepts

- dealing with various different data type formations. I.E. Defensive_personnel = (DB, DL, LB) Also = (FS, FCB, SCB, ILB, OLP, ODL, Etc)
- Dealing with high unknown data in categorical features, used different strategies, most_frequent, drop_rows, and replace with UNKNOWN.
- Had to create the dataset by joining multiple datasets together to create the desired feature set.
- Identified useful features from 300+ features
- Performed EDA on how multiple features interact with each other.
